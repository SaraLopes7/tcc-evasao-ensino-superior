# Checklist final do TCC

## Conteúdo científico

- [x] Problema de pesquisa definido e alinhado ao experimento.
- [x] Objetivo geral compatível com a pergunta de pesquisa.
- [x] Objetivos específicos contemplados pela metodologia e pelos resultados.
- [x] Hipóteses H1, H2 e H3 explicitadas e retomadas na discussão e na conclusão.
- [x] Unidade de análise delimitada como UF × período.
- [x] Distinção entre previsão agregada e risco individual explicitada.
- [x] Cenários A e B definidos de forma consistente.
- [x] Expanding Window e Rolling Window descritos com os mesmos períodos de teste.
- [x] Prevenção de vazamento de dados descrita.
- [x] Cinco abordagens do experimento documentadas.
- [x] MAE, RMSE e R² explicados.
- [x] Análise de erros e interpretabilidade documentadas.
- [x] Limitações declaradas sem extrapolar os resultados.

## Coerência entre capítulos

- [x] Terminologia padronizada para UF, período, Cenário A, Cenário B e validação temporal.
- [x] Resultados e discussão utilizam os mesmos valores experimentais.
- [x] Discussão não transforma importância preditiva em causalidade.
- [x] Conclusão retoma as três hipóteses de forma compatível com os resultados.
- [x] A contribuição é apresentada como comparativa e preditiva, sem alegar inexistência de trabalhos anteriores.

## Referências

- [x] As principais obras citadas no texto constam na lista de referências.
- [x] Tinto (1975) consta nas referências.
- [x] Mançano, Monteiro e Carmo (2026) consta nas referências.
- [x] INEP consta como fonte de dados.
- [x] Breiman (2001), Friedman (2001) e Hoerl e Kennard (1970) constam para fundamentar os modelos correspondentes.
